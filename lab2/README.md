## Вариант 46. Подсчёт слов в файлах

### Краткая постановка задачи

Каркас счётчика слов.

### Развёрнутое описание

- Переменные: `words = 0`, `chars = 0`.
- Команды: `add <строка>`, `report`, `exit`.
- `add` увеличивает `words` на количество пробелов + 1 и обновляет `chars`.
- `report` выводит статистику.
- Предусмотрена обработка пустой строки.

### Критерий 100% завершения

- Подсчёт слов и символов корректен.
- Пустая строка даёт 0 слов.
- Команда `report` выводит статистику.
- В Git есть коммит `lab2: каркас счётчика слов`.
